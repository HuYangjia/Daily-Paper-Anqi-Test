一句话核心贡献
LLM agent 的失败在第 1 轮就可从残差流预测 —— 用 recall-controlled probe cascade 节省 47% 推理算力，并附可认证 recall 上限。
摘要翻译（忠实原文）

LLM agent 在解多步任务时经常锁定到注定失败 的轨迹上，但仍会在失败可观察前消耗大量推理算力。我们表明失败在早期就可从 agent 的内部表征预测：在隐藏激活上做的每轮独立轻量 probe，早在第一次交互轮 就能预示最终 episode 失败——而只读 agent 可观察行为的 scorer 此时几乎与随机猜测无异。我们把这个信号转化为一个可用的中止级联：每轮一个分布无关的校准闸门，通过联合搜索每轮 recall 预算，使得最终成功的 episode 以用户指定的全局速率通过所有闸门——这个 episode 级保证才是部署真正关心的，因为 false-abort 风险会沿闸门累积。在 TextCraft 上，跨两个 agent 模型的级联在90% 到 97% 的每一个 recall target 都达标；在 90% target 下，节省推理算力 47.1% ± 10.3%（Qwen-2.5-7B） 和 37.2% ± 8.8%（Llama-3.2-3B），是最优单闸策略的 1.6–1.7 倍。用同样 pipeline 但只读行为的对照级联只省下大约一半，且在 probe 上叠加行为特征无任何进一步收益——隐藏状态已经编码了行为所揭示的一切。最后，我们刻画了认证高 recall target 的样本复杂度，告诉实践者他们的数据能——以及能证明不能——背书哪些 recall 承诺。代码将开源。

核心内容解读（500 字）

解决了什么问题：Claude Opus / Qwen / Llama 等 agent 在 TextCraft、SWE-bench、WebShop 这类多步任务中，大量 episode 从第 1 轮就已注定失败——但代理会继续消耗几十 K token 推理才让失败变得可观察。这不仅浪费算力，更是agentic safety 的浪费型风险面：越多失败 episode 消耗越多算力，越难在真正 unsafe 状态发生前介入。行为 scorer 在第 1-2 轮几乎与随机猜测无异（AUC 差异 0.12-0.21），也无法作为早停信号。

核心方法：三件套。（1）Probe 侧：每轮独立训一个 逻辑回归 probe（L2 正则 C=1），输入是 agent LLM 在动作 token 最后位置的残差流（Llama-3.2-3B 第 14 层 / Qwen-2.5-7B 第 20 层，per-layer AUC sweep 选出），用 task-grouped k-fold cross-fitting 保证每个 episode 由未见 task 的 probe 打分。（2）Cascade 侧：每轮 gate 用分布无关 Clopper–Pearson 精确二项下置信界（不是普通 conformal quantile），选最小满足 p̲(τ_r) ≥ t_r 的阈值——附录实验显示在 target 0.95 下 quantile 版本会违反 recall（0.933 < 0.95），Clopper–Pearson 达 0.972（保守但从不违反）。6 个 gate × 每个 6 档 budget = 6⁶ = 46,656 组合，在 validation split 联合搜索使全局 recall ≥ ρ*（默认 δ=0.02 安全 margin）。（3）Sample complexity 侧：Rule of Three 界给出 n_pos ≥ ln(α)/ln(ρ*)，本文数据规模下可认证 recall 上限约 0.974——0.98 和 0.99 target 即便"不中止任何 episode 的 no-op 策略"也无法认证，认证变体直接 abstain 并给出零节省。

与现有工作的突破点：三条独立立场。（i）与 7-06 AgentLens（可解释派 hidden representation steering） 同源但目标不同——AgentLens 抑制有害执行，本文中止整个 doomed episode。（ii）与 7-03 BOA（搜索派） 互补——BOA 用工程加速找到 unsafe trajectory，本文用工程加速杀掉 doomed trajectory。（iii）与 6-30 Action Alignment · 7-01 Epistemic Property · 7-07 Cedar Policy 完全正交——那些派系关心"该不该做"，本文关心"何时应该停"。H2 agent safety 第八派立场诞生：早期终止派 / 预算派——八派为 外置 · 认知 · 泛化 · 评委 · 搜索 · 可解释 · 形式化 · 终止。

关键工程决策：Clopper–Pearson 而非 conformal quantile · logistic 而非 MLP probe · 每轮独立而非序列建模 · sample complexity 显式认证边界——每一处都选保守但可保证 而非"看起来更强但可能违反 recall"，这是 recall-controlled safety 领域的方法学示范。

2. Cascade vs 最优单闸：在 90% target 下 1.6–1.7 倍提升；surface single-gate → surface cascade 提升 3.6×，probe single-gate → probe cascade 提升 1.9×——cascade 结构对弱 scorer 的放大更明显。

3. Probe vs 行为 scorer（target 0.95 固定 pipeline，只换 scorer）：

  • Qwen: probe 32.0% 节省 · surface 17.0% —— hidden state 让节省几乎翻倍
  • Stacking (Probe + 行为特征) 与 probe 单独持平（噪声内）—— hidden states 已编码行为揭示的一切，反之则不成立
  • Probe 相对 surface 在第 1-2 轮有 0.12–0.21 AUC 绝对优势；behavior 信号要到第 3-4 轮才成熟——此时已有 1/3+ episodes 结束

4. Sample complexity 认证：n_pos = 113/115 支持 recall ≤ 0.974；0.98 target 需 1.3× 数据；0.99 target 需 2.6× 数据——认证变体在 0.98/0.99 直接 abstain（零节省），诚实告知"这个承诺你的数据背书不了"。

5. 典型最优 budget 向量（Llama, target 0.90）：(0.95, 0.85, 0.85, 1.0, 1.0, 1.0)——在早期 gate（recall 便宜、剩余算力多）激进消耗预算，在末期 gate 关闭。

对研究方向的启发
对 Agent Safety

H2 首月 8 派立场完全闭合：外置（6-30 Action Alignment）· 认知（7-01 Epistemic）· 泛化（7-02 Why Generalize）· 评委（7-03 Necessary but Not Sufficient）· 搜索（7-03 BOA）· 可解释（7-06 AgentLens）· 形式化（7-07 Cedar）· 终止（本文）。本篇是第三派可运行时部署（前两派为 7-06 AgentLens hidden representation + 7-07 Cedar Policy runtime enforcement）；且是唯一一派把"经济学 / 算力预算"作为 first-class 安全变量——把"unsafe episode 是浪费型风险"变成可量化的中止决策。跨谱系融合方向：（1）与 7-06 AgentLens 组"hidden-state 双翼"——一个 abort（本文）、一个 steering（AgentLens），共用残差流基础设施；（2）与 7-07 Cedar Policy 组"硬约束 + 软预算"——Cedar 定义 什么不能做，本文定义 什么时候应该停；（3）与 7-03 BOA 组"搜索 + 终止"——BOA 找不安全轨迹、本文杀 doomed 轨迹，工程加速三件套（batched decoding / prefix caching / chunked tree expansion）可复用。

对 Harness Engineering

本文 probe cascade 是harness 的中止层——与今日 harness 方向的 Harness MDP / Learned Harness（2607.05458）互为对偶：那篇学"什么时候做什么动作"，本文学"什么时候应该完全停下"。两者叠加自然：AW controller 输出"submit"动作时先经过 probe cascade 校验——一个 harness-level early-abort gate。对 Loop Engineering（7-02）：本文为 Loop Library 提供了新的 terminal state 触发器 类型——"probe-signaled doomed"；对 ReContext（7-06）：evidence pool 组装前先跑 probe，doomed episode 直接不做 replay 也可省算力。对 evalci（7-07 · 统计层）：per-round recall guarantee 提供了 harness 报告新维度——不只报最终 rubric，还报"本 harness 在 X% recall 下省 Y% 算力"。工程侧：与你毕设 SGLang KV-cache 优化完美对齐——doomed episode 早停释放的 KV-cache 可以立刻回收给下一个待处理请求，是 KV-cache scheduler 的一个自然 hook。

对 Benchmark

本文为 agent benchmark 引入 两个新的核心指标：（1）成功率 × 算力节省 曲线（不同 recall target 下的 pareto frontier）——比 TextCraft/AgentBench 只报最终成功率信息量大得多；（2）可认证 recall 上限——把"你的 benchmark 数据能背书什么样的部署承诺"做成第一等公民，与 7-07 SovereignPA-Bench 主张的 evidence + auditability 精神一致；与 7-06 SafetyRepro 主张的 configuration-conditional rank instability 互补——前者说"pairwise 判定不稳"，本文说"承诺认证要显式声明数据范围"；与 7-02 IRT（心理测量派）互补——IRT 精选高信息量 items，本文用少量成功 episodes 认证 recall 上限，两者都在做"少样本、多信息" 的评估经济学。H2 benchmark 方法学七联雏形：物品 · 搜索 · 评委 · 构造 · 配置 · 价值观 · 承诺认证（本文启发）。
