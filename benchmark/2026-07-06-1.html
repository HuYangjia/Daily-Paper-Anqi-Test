一句话核心贡献
给 alignment benchmark 最基础的"A 比 B 安全" 配对判定建立形式化可复现闭环——用有限包络命题 把 pairwise disagreement rate 与 configuration-pair reversal 数学地绑定，用 commit-stamped 协议 落到每一个 benchmark，实证证明configuration 单变量就足以翻转配对结果；给出 2026 H2 benchmark 方法学最后一角配置侧鲁棒性 的第一份完整答案。
摘要（中文翻译，忠实原文）

从 foundation-model benchmark 得出的配对模型比较（"A 比 B 更安全"）常被解读为定量裁决，然而它依赖于 benchmark 论文未充分披露 的 harness 选择。我们在这一原语上闭合一次理论—benchmark 循环：一条 有限包络命题（finite-envelope proposition），将可测量的 pairwise-disagreement rate 与严格排序是否允许 configuration-pair 翻转 数学地绑定；并配以一份 commit-stamped 评估协议 在广受引用的 alignment benchmark 上把它可操作化。在每一个 我们测试的 benchmark 上，configuration 选择单独一项 就能翻转配对裁决；该命题把这类严格翻转失效模式独立分离出来。

核心内容解读（问题 / 有限包络命题 / commit-stamped 协议 / 结论普遍性 / 方法学五联拍）

问题背景。2026 年 alignment benchmark 处在一个信誉危机：SafetyBench / HarmBench / TrustLLM / AIR-Bench / AgentBench / OpenLLM Leaderboard 每天都在发布"A 比 B 更安全" 的裁决——但业内很少讨论一个基础问题：如果我把 harness 参数微调，同一对模型 A/B 的排序会不会颠倒？ 现有 benchmark 论文普遍不披露：system prompt / max_tokens / temperature / sampling seed / batching / repetition / grader model / grader config / commit hash / OS / GPU / driver version —— 这些看似周边 的参数，其实决定 pairwise verdict。SafetyRepro 是第一次系统性把这个 folklore 抬到形式化命题。

有限包络命题：一次紧凑的理论突破。命题的直觉是：把每一个"A vs B 配对" 看作二元裁决 → 收集若干 configuration 下的裁决 → 计算 pairwise disagreement rate（多少比例的 configuration 组合给出不同的 verdict）→ 若该 rate 落在某个可测量的有限包络 之内，则严格排序必然 存在configuration-pair 使其翻转。这看似简单，但它的价值在于三点：

特性意义
有限包络不是渐近界，是可在有限次实验内验证 的构造性命题——benchmark 论文可以直接把 disagreement rate 报出来当健康指标
Configuration-pair reversal把"严格排序" 这个 leaderboard 常用的强论断显式化——不是"A 和 B 差不多"，而是"存在一对 configuration 让排序严格颠倒"
可证伪命题给出了具体的边界——一旦 disagreement rate 超过某阈值，"A 比 B 安全" 就失去 pairwise 意义

Commit-Stamped 评估协议：把理论落到可复现工程。光有命题不够，作者配了完整协议：每一次 benchmark run 都必须记录：(a) benchmark 代码 commit hash；(b) harness config 完整 dump；(c) grader model + grader config；(d) sampling seed；(e) OS / GPU / driver stack；(f) run start/end wallclock。协议要求 leaderboard 只接受 commit-stamped submission；两次 run 只有当所有 stamp 一致时才可比较——否则视为不同的 measurement。这与 7-03 Grader-Repro 的K-run disagreement 建议高度呼应：protocol 侧的 stamp × grader 侧的 K-run 组成双侧 audit。

结论的普遍性。论文最有冲击力的结论是"在每个测试的 benchmark 上，configuration 单变量都能翻转 pairwise verdict"——不是偶发现象 而是普遍规律。这意味着：现在 leaderboard 的排序本质上是 configuration-conditional；没有 configuration audit 的 pairwise verdict 只是某一次 configuration 上的观察；论文里"A > B 3 分" 这种论断无法从一次实验推广到 pairwise 判断。这对整个 alignment benchmark 生态 是一次范式冲击。
