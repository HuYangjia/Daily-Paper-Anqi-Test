摘要（中文翻译，忠实原文）

语言模型的 safety benchmark 通常在静态范式 下评估：把所有条目视为对所有模型同等信息量——但对对抗性、高度异质 的 safety 条目而言，这个假设特别问题。全量应用于现代 benchmark 套件，当前评估流程需要10⁵ 数量级响应，其中大多数对排名信号贡献极小。本文分析一组广泛使用的 safety benchmark 并给出三项 高效 safety 评测贡献。第一，展示项目反应理论（IRT） 能在 safety benchmark 上恢复可解释结构——ability 估计能分辨 raw safety metrics 天花板处聚集的模型群。第二，展示 adaptive item selection——根据模型响应动态 选择信息量最大 的条目——能近似 全 benchmark 排名，同时将评测成本至少降 80%（在 Spearman ρ > 90% 与全 benchmark 相关的 benchmark 上）、在 AIR-Bench 2024 上降至 99.9%。第三，引入一种实用流程用于抽取一份跨模型可复用的固定信息量子集——为 adaptive selection 提供替代方案，在 AIR-Bench 2024 上省 99.8%。综合三项，说明心理测量学方法能在 safety 评测流水线全线 实现benchmark-aware 的评测成本削减。

核心内容解读（问题 / IRT 是什么 / 三项贡献 / 与穷举派张力 / benchmark 方法学谱系）

问题背景。H1 末到 H2 首，safety benchmark 数量爆炸：DECOMPBENCH / AgentSecurityBench / HarmBench / AIR-Bench / TrustLLM / OopsieVerse / ForesightSafety-VLA / REALM ……每个 benchmark 少则数千、多则数十万 items。全量组合起来，评测一个模型 需要10⁵ 数量级响应。但作者观察到：其中大多数响应对模型排名贡献极小——因为不同 items 对模型 ability 的区分度 差异很大。这就是信息经济学问题：如何用最少的评测点得到最好的排名信号？教育测量学早在 1960 年代就解决过完全同构的问题——那就是Item Response Theory（IRT）。

IRT 是什么。IRT 是心理测量学的经典理论，最广为人知的应用是标准化考试（SAT / GRE / TOEFL）的自适应组题。它的核心假设是：一个 item 被答对的概率取决于 (a) 该 item 的难度 β 和 (b) 该受测者的能力 θ 的差——最简单的 Rasch 模型是 P(correct | θ, β) = sigmoid(θ - β)；2PL 加入 discrimination 参数 α；3PL 再加入 guessing 参数 c。IRT 给每个 item 计算一个Fisher 信息量——量化"这个 item 对本受测者 ability 估计的贡献"。信息量高的 item = 信息量高的题目，被优先选择。本文的核心洞察是：把 IRT 直接搬到 LLM safety benchmark 上—— LLM 是"受测者"，每个 safety item 是"考题"，回答 refusal / harmful 等就是二值 response。

贡献一：IRT 恢复可解释结构。H1 末以来，很多前沿模型在 safety benchmark 上都达到"90+ safety score 天花板"，raw metric 已经无法 分辨谁比谁更安全。IRT 给每个模型估一个 ability θ——即使 raw score 相同，θ 也不同，因为它们答对的难题 和答错的简单题 分布不同。本文展示 IRT 恢复的 ability 估计 能显著分辨这些聚集在天花板处的模型，得到"比 raw metric 更细粒度" 的排名信号。这就是本文的第一贡献：IRT 不只是省成本工具，它本身在模型能力可解释性 上打开新窗口。

贡献二：Adaptive item selection · 至少省 80%。这是 IRT 最著名的应用——Computerized Adaptive Testing (CAT)——搬到 LLM safety benchmark 上：

  • 从一个先验 ability θ₀ 开始（e.g., 中等能力）。
  • 选择当前 ability 估计下 Fisher 信息量最大的 item——即"最能区分本模型能力" 的 item。
  • 让模型回答该 item，更新 ability 估计。
  • 重复上一步直到 ability 估计的标准误 < 阈值 停止。

结果：在 Spearman ρ > 90% 与全 benchmark 排名相关的 benchmark 上，adaptive 至少省 80%；在 AIR-Bench 2024 上省 99.9%——原来跑 10⁵ 响应，现在只需要 100 个 items 就能得到排名 > 99% 相关的评测。

贡献三：Fixed informative subset · 省 99.8%。Adaptive 有一个操作缺点：需要在线——每次评测一个模型都要动态生成序列。作者补上第三招：离线 找出 benchmark 中信息量前 k% 的固定子集，之后所有新模型直接用这个固定子集评测。结果在 AIR-Bench 2024 上省 99.8%（比 adaptive 稍差但绝对够用，且流程更简单）。

与"穷举派" 的张力。把本文放进 H1 末到 H2 首的 benchmark 方法学谱系，它是心理测量派 的立场宣言，与穷举派 形成互补性张力：

心理测量派与穷举派的张力不是"哪个对"——而是"穷举派构建高质量条目库，心理测量派高效用"——两者需要合作。本文的价值恰恰是：给穷举派做的所有 benchmark 提供一个可选的经济化上层。

方法学后果。本文的 IRT 框架不限于 safety——可以立即扩展到能力评测（HELM / MMLU / BigBench）、agent benchmark（AgentBench / OSWorld / STAGE-Claw）、rubric benchmark（RUBAS）。H2 明显的 follow-up 是把 IRT 加入 agent benchmark 流程——这可能是下半年benchmark 方法学 最重要的空缺。此外 IRT 天然兼容 6-28 Hacker-Fixer Loop 的对抗组卷 —— 用 hacker 生成难题、fixer 生成简单题，IRT 就能把它们放到同一 ability 尺度 下比较。

Safety Benchmark（本文所属方向）

(1) IRT 是 H2 benchmark 领域第一优先 的工具 —— 你之前追踪的 REALM / OSWorld 2.0 / ForesightSafety-VLA / OopsieVerse / STAGE-Claw / TAC / Anchor 都可以立即受益：给每个 item 计算 Fisher 信息量、adaptive 或 fixed 子集选择，成本立降数量级；(2) agent benchmark × IRT：agent benchmark（OSWorld 2.0 / AgentBench / MyPCBench）的 tasks 天然异质——IRT 应用比 QA benchmark 更容易得到 discrimination 信号；(3) rubric × IRT：RUBAS 的四维 rubric 每一维都是 Rasch 尺度上的 item——IRT 可以把多维 rubric 合成一个 ability 分数；(4) Hacker-Fixer × IRT 组合：Hacker 生成难题、Fixer 生成简单题——两者共同校准 IRT 尺度，避免 fixer 提供的 items 全落在低 discrimination 区；(5) 心理测量派 × 拓扑派：Position: Interaction Topology (5-01) 的三种拓扑失效模式可以被 IRT 转化为item 属性——每个多 agent item 附加"拓扑相关性" 元数据，IRT 就能揭示"拓扑变化对 ability 估计的贡献"；(6) IRT 对 benchmark 陈化的诊断——当 fixed informative subset 中大多数 items 变成低 discrimination，就是benchmark 陈化 的信号，需要引入新 items；(7) H2 follow-up 方向："Agent Benchmark IRT-Adaptive Framework"——把 IRT 完整落到 agent benchmark（OSWorld 2.0 / STAGE-Claw / ERP-Bench），这是下半年可预测的高被引方向。

Harness Engineering（毕设参照）

(1) 把 IRT 引入 harness 评测 —— 你的 SGLang KV-cache 毕设需要 harness benchmark 来说话，但完整跑一遍 harness benchmark 太贵；IRT-adaptive 让你的 benchmark 报告可信度不掉，同时省 > 80% 评测成本；(2) Cache decision × Fisher information：把"下一次 cache 决策该选哪个策略试" 建模为"当前 ability 估计下 Fisher 信息量最大的选择"——直接把 IRT 的 CAT 算法搬到 cache policy 选择；(3) 与 7-02 Loop Engineering 的 verification ladder 组合：ladder 五级本身是五个不同 discrimination 区 的 items，IRT 可以给"每个 loop 用哪一级 verification" 提供数据驱动的选择；(4) 与 6-30 CUGA FLO 的 hook 组合：hook 触发次数是ability 估计的证据——high-ability agent 触发 hook 少，low-ability 触发多；IRT 让 hook 数据变成 ability 信号；(5) Fixed informative subset for harness——SGLang 上不需要跑完整 benchmark，只跑 10² 数量级的 fixed subset 就能说"我的 cache 策略在 IRT 尺度上比 baseline 强"；(6) Benchmark-aware post-training 联动：与 6-25 Interplay of Harness and Post-Training 组合——post-training 时选择IRT 高信息量 items 作为训练目标，避免训练数据的浪费；(7) 毕设结果部分设计：报告可以用"IRT ability 分数 + 全 benchmark ρ 相关性 + 评测节省 %" 三元组——比只报 raw accuracy 更专业、更 defensible。

Agent Skills Safety

(1) IRT × 三派 H2 立场谱系——外置派 / 认知派 / 泛化派都依赖 benchmark 数据支撑立场，IRT 让这些数据更少 但更 informative；(2) skill-level ability estimation——把每个 skill 视为"受测者"，把 red-team 攻击视为"考题"，每个 skill 得到一个安全 ability θ_skill；θ 低的 skill 优先加固；(3) 与 6-30 Action Alignment 的 C/R/B 三坐标组合：Action Alignment 建议 relational deployment-conditioned 三坐标分别 report——IRT 可以给每个坐标 单独估 ability，避免三坐标合成损失信息；(4) 与 7-01 Epistemic Property 的 SMA 五轴组合：SMA 五轴（ℋ 假设空间 / 𝒜 更新算子 / ℳ 元决策层 / 世界模型 / 目标）每一轴都是ability 维度——多维 IRT 可以同时估五轴，得到 teachability 的数值化 表示；(5) 与 7-02 Loop Engineering 的五级 verification ladder 组合：ladder 五级 × 五种 discrimination 区——safety verification 应按当前 ability θ 自适应 选择 ladder 级别，低 ability agent 走 human-only，高 ability 走 autonomous-zone；(6) 与 7-02 Why Generalize 的 Lipschitz 上界组合：Lipschitz gap 告诉我们安全泛化的本体难度，IRT 告诉我们安全评测的信息经济——两者组合让 skill safety 既诚实 又可扩展；(7) skill red-team 数据高效化：H1 末 red-team benchmark 都在规模化，但缺 IRT——如果给 REALM 或 SkillSafetyBench 加一层 IRT，前 100 个 items 就能得到全 benchmark 相关的 ability 排名。
